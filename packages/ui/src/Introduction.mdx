# Dodie Thayer for Tory Burch — Design System

A component library built with **Atomic Design methodology**, capturing the editorial luxury aesthetic of the Tory Burch × Dodie Thayer collaboration.

---

## 🎨 Design Principles

1. **Editorial Luxury** — Every component communicates refinement through restrained typography and generous whitespace
2. **Botanical Warmth** — The palette draws from Dodie Thayer's hand-painted botanical work: cream, sage, terracotta, blush, gold
3. **Craft & Precision** — Interaction states (hover, focus, active) are deliberate and smooth, never jarring
4. **Accessibility First** — All components meet WCAG 2.1 AA standards

---

## 🏗 Architecture

This design system is structured following **Atomic Design** (Brad Frost):

```
packages/
├── tokens/          Design tokens — colours, typography, spacing, shadows
└── ui/
    └── src/
        ├── atoms/         Irreducible building blocks
        │   ├── Button     Primary CTA element
        │   ├── Text       Polymorphic typographic atom
        │   ├── Badge      Product status labels
        │   ├── Tag        Filter/category chips
        │   ├── Link       Animated anchor variants
        │   ├── Icon       SVG icon set
        │   └── Divider    Section separators
        │
        ├── molecules/     Purposeful groups of atoms
        │   ├── ProductCard      Shoppable product unit
        │   ├── NavigationItem   Nav link + mega-menu
        │   ├── SearchBar        Search input
        │   └── MediaCaption     Editorial text block
        │
        └── organisms/     Complex UI sections
            ├── Header           Site navigation
            ├── HeroBanner       Campaign hero section
            ├── ProductGrid      Browsable product listing
            ├── EditorialBlock   Split-screen storytelling
            ├── CollectionCarousel  Scrollable product row
            └── Footer           Site footer
```

## ✍️ Typography

| Role | Font | Style |
|------|------|-------|
| Editorial headlines | Playfair Display | Light / Regular, tracked tight |
| All-caps labels | Inter | Medium, `tracking-luxury` (0.25em) |
| Body copy | Inter | Regular, relaxed line-height |
| Price | Inter | Medium |

---

## 📐 Spacing

Built on an **8px base grid**. Semantic tokens:

- `componentMd` = 16px (standard padding)
- `gutterDesk`  = 32px (column gap)
- `sectionDesk` = 96px (section vertical rhythm)
- `maxContent`  = 1440px (max-width constraint)
